## 📖 Project Overview

A **Minimum Spanning Tree (MST)** is a subset of the edges of a connected, weighted graph that connects all vertices without forming cycles while minimizing the total edge weight.

This project explains the concepts of MST, demonstrates how Prim's and Kruskal's algorithms work, and compares their approaches, time complexities, and applications.

## 📊 Algorithm Comparison

| Prim's Algorithm | Kruskal's Algorithm |
|------------------|---------------------|
| Starts from any vertex | No fixed starting vertex |
| Grows a single tree | Builds a forest of trees |
| Best for dense graphs | Best for sparse graphs |
| Uses Priority Queue | Uses Union-Find |
| Time Complexity: O(E log V) | Time Complexity: O(E log E) |
